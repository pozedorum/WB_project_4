# Go Metrics Dashboard

📊 Дашборд для мониторинга метрик Go приложения в реальном времени

## Возможности

- Мониторинг памяти, сборщика мусора и аллокаций
- Веб-интерфейс с графическим отображением
- Метрики в формате Prometheus
- Тестовые инструменты для аллокации памяти

## Cтарт

```bash
# Запуск
make run

```

Откройте http://localhost:8080

## API Эндпоинты

- `GET /` - Веб-дашборд
- `GET /metrics` - Метрики Prometheus
- `GET /api/system` - Полная статистика (JSON)
- `GET /api/allocations` - Статистика аллокаций (JSON)
- `GET /api/gc` - Статистика сборщика мусора (JSON)
- `GET /api/memory` - Использование памяти (JSON)
- `GET /api/alloc` - Тестовая аллокация памяти

## Сборка

```bash
make build    # Собрать бинарник
make run      # Запустить
make lint     # Проверить код
make clean    # Очистить артефакты
```


Для тестирования всех эндпоинтов есть кнопки на фронтенде, при аллокации памяти, если выделить 1 мб gc не запустится сразу, если 10 мб, то gc запустится и это можно будет увидеть в метриках.
